# Roadmap

The detailed plan is `.ai/MASTER_PLAN.md`.

## Current release sequence

1. Foundation, secure document and durable execution baseline: complete.
2. Integration and acceptance evidence: in progress.
3. Security and dependency evidence: in progress; OWASP scan is not yet green.
4. Operations readiness: backup/restore, observability, load and rollback drills.
5. Staging/canary release review.
6. Optional platform expansion: WebSocket, OCR, search and browser tools.

The platform is suitable for development and an internal pilot, not formal
production release, until the P0/P1 checklist has recorded evidence.
