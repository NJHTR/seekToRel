# Projects

Each product is a bounded initiative with its own product, architecture,
frontend, backend, tests, security and docs folders. Shared code is consumed
through an API or module contract; copying another project's implementation is
not an ownership model.

## Project IDs

- `mac-for-web`: desktop shell, window manager, app manifests and portfolio UX.
- `nexus`: user-facing experiment-report automation application.
- `portfolio-apps`: Store, Reddit, Weather and future showcase applications.
- `reportai-platform`: Java platform capabilities shared by Nexus and future
  document/automation products.

Use the template in `_template/` for a new project. A project cannot enter
development until its product brief, architecture note, threat model and test
strategy exist.
